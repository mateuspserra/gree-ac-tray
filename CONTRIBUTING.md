# Como contribuir

Contribuições em português brasileiro são bem-vindas.

## Relatar um problema

Abra uma issue com os passos para reproduzir, o comportamento esperado, o que aconteceu e as versões do Windows, Python e aplicativo. Quando relevante, informe o modelo e o firmware do aparelho.

Não publique chaves de comunicação, endereços MAC ou registros completos sem revisar os dados: a biblioteca pode registrar informações de identificação e chaves durante a conexão.

## Propor uma alteração

1. Crie um fork e uma branch para a mudança.
2. Instale as dependências conforme o README.
3. Verifique o modo de demonstração e as telas afetadas.
4. Para mudanças de comunicação, informe se houve teste com aparelho real e qual modelo foi utilizado.
5. Abra uma solicitação de alteração com título e descrição em português, explicando o problema, a solução e a validação realizada.

Use português nos textos da interface, comentários e documentação. Preserve os nomes de bibliotecas, APIs e argumentos necessários para a integração.
